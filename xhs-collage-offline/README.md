# 方格志 · 小红书离线拼图工具

纯本地运行，不调用任何 AI 服务。支持多图片页、项目素材库、跨页素材使用状态、整图一二级标题、格子备注、统一模板、单页样式和固定 1080px PNG 导出。

## 功能

- 自定义 `列数 × 行数`，提供 3×3、4×3、3×4、5×5 预设。
- 一次导入任意数量的本地图片，再点击、长按或拖动到格子。
- 红色标记本页已用素材，蓝色标记其他页已用素材。
- 每张成品图有一个一级标题和一个可选二级标题，每个格子可填写备注。
- 只有内容真正发生变化时才会自动保存；初始化、打开项目和切换图片页不会误建项目。
- 项目库支持打开和确认删除项目；删除会同步移除 SQLite 中的数据。
- 全项目统一样式，也可为某张图片单独设计。
- 自然、暖色、清冷、明亮、胶片五种本地统一色调。
- 项目保存到本地 SQLite，局域网设备可共同访问。
- 导出宽度固定为小红书高清规格 1080px。
- 画布预览缩放位于显示区标题栏旁，电脑和手机都可直接调整。

## 运行

需要 Node.js 和 Python 3.10+。

在仓库根目录启动网页：

```powershell
npx vite xhs-collage-offline --host 0.0.0.0 --port 8765
```

另开终端启动本地草稿服务：

```powershell
python xhs-collage-offline/server.py
```

电脑访问 `http://127.0.0.1:8765/`。手机访问 `http://电脑局域网IP:8765/`，并确保防火墙允许 8765 和 8766 端口。

草稿保存在 `xhs-collage-offline/drafts.db`，该文件不会提交到 Git。

## 文件

- `index.html`：完整前端，无第三方前端依赖。
- `server.py`：Python 标准库实现的 SQLite 草稿 API。
